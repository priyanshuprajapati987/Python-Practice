# Beginner Python Practice

Try each **before** checking `solutions/beginner.py`.

---

### Q1. Type conversion
What is `int("42")` and `str(3.14)`?

### Q2. Power operator
What is `2 ** 5`?

### Q3. String indexing
For `s = "code"`, what is `s[1]` and `s[1:3]`?

### Q4. Membership in string
For `s = "hello world"`, what is `"world" in s`?

### Q5. `count`
What is `"banana".count("a")`?

### Q6. While loop
What does this print?
```python
i = 0
while i < 3:
    print(i, end=" ")
    i += 1
```

### Q7. List `pop`
For `a = [10, 20, 30]`, what does `a.pop()` return and what is `a` after?

### Q8. `round`
What is `round(3.14159, 2)`?

### Q9. Comparison chaining
What is `1 < 2 < 3`?

### Q10. Ternary
What does `x = 5; "yes" if x > 3 else "no"` evaluate to?

### Q11. `abs`
What is `abs(-7)`?

### Q12. `split`
What is `"a,b,c".split(",")`?

### Q13. List `insert`
For `a = [1, 2, 3]`, what does `a.insert(0, 9)` make `a`?

### Q14. `replace`
What is `"hello".replace("l", "L")`?

### Q15. `in` with list
For `a = [1, 2, 3]`, what is `4 not in a`?

### Q16. `len` of list
What is `len([1, [2, 3], 4])`?

### Q17. `min`/`max` with strings
What is `min("zebra", "apple")`?

### Q18. Chained assignment
After `a = b = 5`, is `a is b` True or False (for small ints)?

### Q19. `print` separator
What does `print("x", "y", "z", sep="-")` print?

### Q20. `range` default start
What does `list(range(3))` produce?
