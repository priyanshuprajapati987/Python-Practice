# Python-Practice 🐍

A **second** public collection of Python practice quizzes — fresh questions
(different from the `Python-Quiz` repo), beginner to advanced, each with a
reference solution. Great for daily practice and interview prep.

## Structure

```
Python-Practice/
├── quizzes/            # Question banks (markdown)
│   ├── beginner.md
│   ├── intermediate.md
│   └── advanced.md
├── solutions/          # Reference solutions
│   ├── beginner.py
│   ├── intermediate.py
│   └── advanced.py
└── quiz_runner.py      # Interactive CLI quiz
```

## Usage

```bash
python quiz_runner.py
```

Or read `quizzes/*.md`, solve, then check `solutions/*.py`.

## Levels

| Level        | Sample topics                                            |
|--------------|-----------------------------------------------------------|
| Beginner     | operators, casting, strings, loops, basic functions      |
| Intermediate | comprehensions, dicts/sets, files, errors, lambdas, OOP  |
| Advanced     | decorators, generators, closures, itertools, concurrency  |

Contributions welcome via PR! 🚀
